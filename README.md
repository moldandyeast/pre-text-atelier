# Pre-Textile Atelier

A pattern-to-garment print studio: set type and graphics on flat pattern pieces, and the browser cuts, sews, prints and drapes them into a cloth simulation on a body, dress form or hanger. Text layout by Weft, measured once with canvas and broken into lines with plain arithmetic.

Live: https://textile-atelier.moldandyeast.com

More at https://content.moldandyeast.com · follow [@nilsedison](https://twitter.com/nilsedison) on Twitter · [source on GitHub](https://github.com/moldandyeast/pre-text-atelier).

## Structure

- `public/index.html` — the deployed piece, one file, no third-party requests. Runs offline when saved to disk. Generated by `npm run build`, committed.
- `src/pre-textile-atelier.html` — the original piece, verbatim.
- `src/credits.css`, `src/credits.html` — the credits bar, spliced in by `build.mjs`.
- `vendor/js-yaml/` — js-yaml 4.1.0 (`dist/js-yaml.min.js` from npm, MIT, licence alongside), inlined in place of the original's cdnjs `<script src>`.
- `wrangler.jsonc` — Cloudflare Worker serving `public/` as static assets on the custom domain. No server code.

The piece sets everything in the system Arial stack, so there is no webfont to ship.

## Build

```sh
npm install
npm run build
```

## Deploy

Deploys are manual, there is no CI. Uses your existing `wrangler login` session.

```sh
npm run deploy
```
